# EGAT Microgrid Intrusion Detection

This repository contains the implementation of the Edge-Optimized Graph Attention Transformer (EGAT) framework for resilient microgrid topology attack identification.

## Dataset
IEEE DataPort DNP3 Intrusion Detection Dataset:
https://ieee-dataport.org/documents/dnp3-intrusion-detection-dataset

## Requirements
Install dependencies using:

pip install -r requirements.txt

## Training
python training/train.py

## Evaluation
python training/evaluate.py
